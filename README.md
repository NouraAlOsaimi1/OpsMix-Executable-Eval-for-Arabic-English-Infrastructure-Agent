# OpsMix-Ar-Executable-Evaluation-of-Arabic-English-Infrastructure-Agents

OpsMix is an executable benchmark testbed and evaluation suite designed for cross-lingual (Arabic and English) Site Reliability Engineering (SRE) and AI Infrastructure Agents. It provides containerized environments and evaluation pipelines to assess model performance across complex system operations and IT infrastructure management tasks.

---

## Overview

* **Cross-Lingual Evaluation:** Benchmark agent performance on infrastructure task execution in both Arabic and English instructions.
* **Executable Testbed:** Leverages isolated Docker containers to execute actions and safely measure actual environment states.
* **Multi-Model Sequential Execution:** Supports automated sequential runs across various LLMs and agent architectures.
